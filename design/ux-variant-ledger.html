Rules are written in English first; the compiled configuration is the carbon copy underneath. Accepting is a verification act. Amending is a deliberate one.

IState a rule in English

The system drafts a rule only from the fifteen check types below. What it can't express, it refuses — with the reason.

Rejected · nothing stored

IIThe menu — fifteen check types, curated

Every rule in this book, suggested or typed, is drawn from this list. A rule outside it cannot be stored — that is a defect, not a feature request.

not be null — column is always present be between — numeric or date bounds be in set — value from a fixed list not be in set — value never from a list be unique — no duplicates in column match regex — text fits a pattern not match regex — text avoids a pattern match strftime — date string fits a format value lengths between — text length bounds be of type — column has expected type mean between — column average in bounds distinct in set — no unexpected categories most common in set — dominant value expected row count between — table size in bounds column to exist — schema still has the column
